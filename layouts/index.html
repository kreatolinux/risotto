Every core tool, written in-house.

A package manager, an init system, a build tool and a DSL, designed to work together, and all written in Nim.

kpkg

package manager

Incredibly feature-packed package manager. Build from source or install binaries. It has a REPL, a modular dependency resolver and atomic operations including rollback.

$ kpkg install flatpak

Jumpstart

init system

Most modular init system to ever exist. Units are Kongue decfiles: more flexible than INI units and safer than shell scripts. Utilizes cores to allow any service to work under it.

Prefer systemd or OpenRC? Use them.

krep

repo & image tool

All you need to create, manage, and maintain Kreato Linux. Includes an ISO generator, a rootfs generator, repository update tools, Kongue linter and more.

rootfs iso check update

Kongue

domain-specific language

One small language behind runfiles, decfiles and more. It is inspired from YAML, sh and HCL. Always improving with more support.
